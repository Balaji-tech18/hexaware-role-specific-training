Part 10 - Document Design

-> product can have five colors so storing it in a  Array is the effective way.
-> customer has one residential address so storing it as a embedded document must be wasy to store the details like city, street, etc.
->Use an array of embedded documents to store various products for an order with the product details as an embedded document inside the array of items.
->product information must be stored as an embedded document 
->Seperate collection for reviews and customer order over years 
->simple field for employee name
->Array for multiple tags for a product so that we can store multiple things about the product.

Explanation 

-> I used an array for categories because a single supplier may supply more than one type of products
-> Contacts contain several details like phone number, email, WhatsApp number etc, so I used an embedded document
-> a supplier may have two or more ware houses located at various location so i used array to store all those.
